## Committing
This repo is public. Every commit must be authored as `Jonathon Taylor <github@jdtay.com>`, never
`jonathon@jdtay.com`. Check `git config user.email` before committing; if it isn't
`github@jdtay.com`, run `git config user.email github@jdtay.com` first. Never push from a clone
whose history predates 2026-10-16 (it still holds the old email); reset it to `origin/main` instead.
